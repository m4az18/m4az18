### How I approach an AI project

I start with the decision the system needs to support, then identify the inputs,
failure conditions and evidence required to evaluate it. I keep model inference
separate from application policy, document thresholds and make unavailable or
unusable evidence an explicit outcome.

The repositories include setup instructions, engineering notes and checks that
can run without private datasets. Model weights and personal media stay outside
version control. Collaborative source is acknowledged where applicable.
